# costycnc-inkscape-1.0

**Inkscape extension created for CostyCNC**

This project provides an Inkscape extension developed for **CostyCNC** to convert SVG paths into G-code and communicate directly with a CNC controller through a serial connection.

Although it was created for CostyCNC, the generated G-code and serial communication can also be used with other CNC machines and GRBL-compatible controllers that accept the commands generated by the extension.

---

## What is it?

The extension adds a **CostyCNC** submenu to Inkscape.

The main workflow is:

**Inkscape → SVG paths → path processing → G-code → Serial → CNC**

It was developed to create a simple workflow where a drawing made in Inkscape can be converted into a CNC toolpath and sent directly to the machine.

The project also contains a second extension for manually moving the CNC from Inkscape.

---

## 🔍 What does `gcode.py` do?

The main extension:

- Works with paths selected in Inkscape
- Applies the complete Inkscape transformation
- Processes Bezier curves
- Subdivides curves into smaller segments
- Finds a starting point close to the machine origin
- Automatically organizes multiple paths using a nearest-point search
- Rotates each path so the closest point becomes its starting point
- Inserts the paths into a continuous toolpath
- Converts Inkscape coordinates to millimeters
- Generates G-code
- Saves the generated `.nc` file
- Sends the G-code directly to the CNC through a serial connection

This is more than a simple SVG-to-G-code conversion. The extension also performs toolpath ordering to reduce unnecessary movement between separate paths.

---

## ⚙️ Path ordering

When several paths are selected, the extension searches for the closest points between the current toolpath and the remaining paths.

The selected path is rotated so that the nearest point becomes its starting point, then it is inserted into the existing toolpath.

The process is repeated until all paths have been included.

```text
SVG paths
    ↓
Find starting point
    ↓
Find nearest path
    ↓
Rotate path to nearest point
    ↓
Insert into toolpath
    ↓
Repeat
    ↓
G-code
```

This algorithm was developed for the CostyCNC workflow.

## 🛠️ G-code generation

The generated G-code includes commands such as:

```gcode
G21
G90
F500
G92 X0 Y0
M03 S1000
G00 X0.000 Y0.000
G01 X10.000 Y20.000
G01 X20.000 Y30.000
...
G01 X0 Y0
M05
```

The exact coordinates and values depend on the selected drawing and extension settings.

The generated file uses the `.nc` extension.

---

## 🔌 Serial communication

The extension communicates directly with the CNC controller through a serial connection.

The current implementation uses:

```text
115200 baud
```

For each G-code line, the extension sends the command through the serial port and waits for a response before continuing.

When the CNC is connected to the selected serial port, the G-code can therefore be sent directly from the Inkscape extension.

---

## ↔️ `move.py`

The repository also contains a second Inkscape extension called **move**.

It provides simple manual movement of the CNC from Inkscape.

The user selects:

- Direction
- Step value
- Serial port

The extension sends a direct movement command through the serial connection.

Available directions:

```text
up
down
left
right
```

This extension is separate from G-code generation and is intended for simple machine movement.

## 🔧 Configuration

### G-code extension

The current `gcode.py` parameters are:

| Parameter | Default | Description |
|---|---:|---|
| Feedrate | 500 | G-code feed rate |
| Temperature | 1000 | Value used for the generated `M03 S...` command |
| Port | COM4 | Serial port |
| DPI | 96 | Inkscape parameter |
| Subdivision | 0.1 | Curve subdivision / contour precision |

**Note:** `temperature` is a historical parameter name. In the current code, its value is used directly as the `S` value in the generated `M03 S...` command.

### Move extension

The current `move.py` parameters are:

| Parameter | Default | Description |
|---|---:|---|
| Step | 10 | Movement value |
| Direction | up | Movement direction |
| Port | com3 | Serial port |

## 📦 Installation

The extension files are contained in the `gcode` folder.

Copy the **contents of the `gcode` folder** into the Inkscape extensions directory.

Typical Windows locations are:

```text
C:\Program Files\Inkscape\share\inkscape\extensions
```

or:

```text
C:\Users\<username>\AppData\Roaming\inkscape\extensions
```

After copying the files, restart Inkscape.

The extension should appear under:

```text
Extensions → costycnc
```

## 🎯 CostyCNC origin

This extension was created for **CostyCNC**.

The objective was to have a direct and simple workflow:

**Draw in Inkscape → select the paths → generate the toolpath → send it to the CNC.**

Because the extension uses serial communication and standard CNC/GRBL-style commands, it can also be adapted or used with other compatible CNC controllers.
